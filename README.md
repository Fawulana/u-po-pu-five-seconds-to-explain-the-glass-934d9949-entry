# Five Seconds to Explain the Glass

The house cat's official statement, delivered in the five seconds after the glass hit the floor:

> It was squatting in my sunbeam rent-free, so I evicted it — in this house, glassware serves the cat, not the other way around.

## Why this line

No apology, no confession, no tired gravity excuse. The cat reframes the crime as property management: the glass was a rent-free squatter in prime sunbeam real estate, and the knock-off was an eviction. Pure cat logic — territorial, self-interested, and quietly convinced the human should be grateful. One sentence, 126 characters, easily spoken before the human finishes gasping.

## How the program works

`main.py` is a program/v1 entrypoint (Python 3, standard library only, deterministic, offline). It writes the line above, byte for byte, to `/output/entry.txt` on every run — UTF-8 text well inside the gate's 1–200 character limit.
